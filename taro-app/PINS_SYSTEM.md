# Система пинов (Достижения)

## Описание

Система пинов позволяет пользователям получать достижения за выполнение различных активностей в приложении Seluna. При разблокировке пина показывается всплывающее уведомление со ссылкой на страницу коллекции.

## Структура

### Redux Store (`pinsSlice.ts`)

- **State**: Содержит массив пинов и текущее уведомление
- **Actions**:
  - `unlockPin` - разблокировка конкретного пина
  - `checkPinConditions` - проверка условий разблокировки
  - `hideNotification` / `clearNotification` - управление уведомлениями
  - `resetPins` - сброс всех пинов (для разработки)

### Компоненты

#### `PinNotificationPopup.tsx`

Глобальное всплывающее уведомление о получении пина:

- Автоматическое скрытие через 10 секунд
- Анимация появления/исчезновения
- Кнопка перехода в коллекцию
- Стиль в духе `ActivityDetailPopup`

#### `CollectionPins.tsx`

Обновленная страница коллекции:

- Использует данные из Redux store вместо моковых данных
- Отображает актуальное состояние пинов
- Кнопка сброса пинов в режиме разработки

## Доступные пины

### 1. "Мастер Аффирмаций"

- **ID**: `affirmation`
- **Условие**: Создание первой аффирмации
- **Изображение**: `pin-affirmation.png`

### 2. "Хранитель Воспоминаний"

- **ID**: `calendar`
- **Условие**: Добавление заметки в календарь
- **Изображение**: `pin-calendar.png`

### 3. "Ученик Таро"

- **ID**: `spreads`
- **Условие**: Проведение первого расклада Таро
- **Изображение**: `pin-spreads.png`

## Логика разблокировки

### Аффирмации

В `useAffirmation.ts`:

```typescript
// При успешном создании аффирмации
dispatch(checkPinConditions({ type: 'affirmation_created', data: parsedData }));
```

### Заметки в календаре

В `calendarSlice.ts`:

```typescript
// При добавлении заметки
dispatch(checkPinConditions({ type: 'calendar_note_added', data: note }));
```

### Расклады Таро

В `calendarUtils.ts`:

```typescript
// При сохранении расклада в календарь
store.dispatch(checkPinConditions({ 
  type: 'tarot_reading_completed', 
  data: { spreadName, deckName, cards } 
}));
```

## Интеграция в App.tsx

Компонент `PinNotificationPopup` добавлен в корневой App компонент как глобальный попап, который показывается поверх всех остальных элементов.

## Тестирование

1. **Разработка**: Кнопка "Сбросить пины" доступна в режиме разработки на странице коллекции
2. **Аффирмации**: Создайте аффирмацию → получите пин "Мастер Аффирмаций"
3. **Календарь**: Добавьте заметку в календарь → получите пин "Хранитель Воспоминаний"
4. **Таро**: Проведите расклад → получите пин "Ученик Таро"
