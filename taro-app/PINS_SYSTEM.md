# Система пинов (Достижения)

## Описание

Система пинов позволяет пользователям получать достижения з## Тестирование

1. **Разработка**: Кнопка "Сбросить пины" доступна в режиме разработки на странице коллекции
2. **Аффирмации**: Создайте 15 аффирмаций → получите пин "Мастер Аффирмаций"
3. **Календарь**: Добавьте 15 заметок в календарь → получите пин "Хранитель Воспоминаний"
4. **Таро**: Проведите 3 расклада → получите пин "Ученик Таро"
5. **Покупки**: Купите любой пакет звезд → получите пин "Коллекционер Звезд"

## Прогресс выполнения

Каждый пин теперь отслеживает прогресс выполнения:

- `currentCount` - текущее количество выполненных действий
- `requiredCount` - требуемое количество действий для разблокировки
- Визуальный прогресс-бар в интерфейсе коллекции пинов
- Отображение числового прогресса "X / Y"зличных активностей в приложении Seluna. При разблокировке пина показывается всплывающее уведомление со ссылкой на страницу коллекции.

## Структура

### Redux Store (`pinsSlice.ts`)

- **State**: Содержит массив пинов и текущее уведомление
- **Actions**:
  - `unlockPin` - разблокировка конкретного пина
  - `checkPinConditions` - проверка условий разблокировки
  - `hideNotification` / `clearNotification` - управление уведомлениями
  - `resetPins` - сброс всех пинов (для разработки)

### Компоненты

#### `PinNotificationPopup.tsx`

Глобальное всплывающее уведомление о получении пина:

- Автоматическое скрытие через 10 секунд
- Анимация появления/исчезновения
- Кнопка перехода в коллекцию
- Стиль в духе `ActivityDetailPopup`

#### `CollectionPins.tsx`

Обновленная страница коллекции:

- Использует данные из Redux store вместо моковых данных
- Отображает актуальное состояние пинов
- Кнопка сброса пинов в режиме разработки

## Доступные пины

### 1. "Мастер Аффирмаций"

- **ID**: `affirmation`
- **Условие**: Создание 15 аффирмаций
- **Прогресс**: Отслеживается каждая созданная аффирмация
- **Изображение**: `pin-affirmation.png`

### 2. "Хранитель Воспоминаний"

- **ID**: `calendar`
- **Условие**: Добавление 15 заметок в календарь
- **Прогресс**: Отслеживается каждая добавленная заметка
- **Изображение**: `pin-calendar.png`

### 3. "Ученик Таро"

- **ID**: `spreads`
- **Условие**: Проведение 3 раскладов Таро
- **Прогресс**: Отслеживается каждый завершенный расклад
- **Изображение**: `pin-spreads.png`

### 4. "Коллекционер Звезд"

- **ID**: `star`
- **Условие**: Покупка звезд (любой пакет)
- **Прогресс**: Разблокируется с первой покупкой
- **Изображение**: `pin-star.png`

## Логика разблокировки

### Аффирмации

В `useAffirmation.ts`:

```typescript
// При успешном создании аффирмации
dispatch(checkPinConditions({ type: 'affirmation_created', data: parsedData }));
```

### Заметки в календаре

В `calendarSlice.ts`:

```typescript
// При добавлении заметки
dispatch(checkPinConditions({ type: 'calendar_note_added', data: note }));
```

### Расклады Таро

В `calendarUtils.ts`:

```typescript
// При сохранении расклада в календарь
store.dispatch(checkPinConditions({ 
  type: 'tarot_reading_completed', 
  data: { spreadName, deckName, cards } 
}));
```

## Интеграция в App.tsx

Компонент `PinNotificationPopup` добавлен в корневой App компонент как глобальный попап, который показывается поверх всех остальных элементов.
