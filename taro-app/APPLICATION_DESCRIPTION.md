# Seluna - Описание VK Mini App для Таро и духовных практик

## 🔮 Общее описание приложения

**Seluna** - это VK Mini App для гадания на картах Таро, получения ежедневных аффирмаций и ведения духовного дневника. Приложение создано для пользователей, интересующихся эзотерикой, духовным развитием и самопознанием.

### Основная концепция
- Персонализированные гороскопы на основе знака зодиака пользователя
- Интерактивные расклады Таро с различными колодами карт
- Ежедневные аффирмации для духовного развития
- Календарь активностей для отслеживания практик
- Адаптивный дизайн для мобильных устройств и десктопа

---

## 🏗️ Техническая архитектура

### Основные технологии
- **React 18** + **TypeScript** - основной фреймворк
- **VK UI** - компоненты интерфейса ВКонтакте
- **VK Bridge** - интеграция с платформой ВКонтакте
- **Redux Toolkit** - управление глобальным состоянием
- **VK Mini Apps Router** - маршрутизация
- **Vite** - сборщик проекта

### Структура проекта
```
src/
├── components/     # Переиспользуемые UI компоненты
├── panels/         # Основные экраны приложения
├── store/          # Redux store и слайсы
├── hooks/          # Кастомные React хуки
├── types/          # TypeScript типы
├── utils/          # Утилитные функции
├── styles/         # CSS стили
├── assets/         # Изображения и иконки
└── constants/      # Константы приложения
```

## 📱 Функциональные модули

### 1. **Главная страница (Home Panel)**
**Файл:** `src/panels/Home.tsx`

**Функционал:**
- Отображение аватара и имени пользователя
- Навигационное меню (расклады, аффирмации, календарь, настройки)
- Секция гороскопа с персонализированными предсказаниями
- Секция исследования Таро с тремя основными направлениями
- Баннер получения звезд (игровая механика)
- Отображение доступных колод Таро

**Ключевые компоненты:**
- `HoroscopeSection` - блок с гороскопом
- `ExploreSection` - блок исследования функций
- `DecksDisplaySection` - отображение колод карт
- `BannerStars` - геймификация

### 2. **Система гороскопов (Horoscope Section)**
**Файл:** `src/components/HoroscopeSection.tsx`

**Функционал:**
- Получение гороскопов через API на основе знака зодиака
- Поддержка трех типов: ежедневный, еженедельный, месячный
- Мультиязычность (русский, английский)
- Анимированные элементы (солнце, луна, звезды)
- Адаптивный дизайн для мобильных устройств
- Отображение цвета дня, счастливого числа, настроения

**Redux слайс:** `horoscopeSlice.ts`
- Управление знаком зодиака
- Переключение типа гороскопа
- Кэширование данных

### 3. **Система расскладов Таро**

#### 3.1. **Просмотр расскладов (Taro Spreads Panel)**
**Файл:** `src/panels/TaroSpreads.tsx`

**Функционал:**
- Отображение различных типов расскладов
- Детальная информация о каждом раскладе
- Переход к процессу гадания

#### 3.2. **Процесс гадания (Taro Reading Panel)**
**Файл:** `src/panels/TaroReadingPanel.tsx`

**Функционал:**
- Двухэтапный процесс: выбор карт → просмотр расклада
- Поддержка drag-and-drop для выбора карт
- Альтернативный режим ручного выбора карт
- Сохранение вопроса пользователя
- Генерация интерпретации расклада

**Ключевые компоненты:**
- `CardSelector` - выбор карт для расклада
- `TaroReading` - отображение готового расклада

#### 3.3. **Колоды карт (Deck System)**
**Файлы:** 
- `src/panels/DeckDetails.tsx` - детали колоды
- `src/panels/CardDetails.tsx` - детали карты

**Функционал:**
- Просмотр доступных колод Таро
- Детальная информация о каждой карте
- Изображения карт и их значения
- Мультиязычная поддержка описаний

**Redux слайс:** `taroDecksSlice.ts`
- Загрузка колод и карт
- Кэширование данных
- Управление текущей выбранной колодой/картой

### 4. **Система аффирмаций**
**Файлы:**
- `src/panels/DailyAffirmationPanel.tsx`
- `src/components/DailyAffirmation.tsx`

**Функционал:**
- Ежедневные персонализированные аффирмации
- Форма для создания собственных аффирмаций
- Отображение результатов аффирмаций
- Сохранение и история аффирмаций

### 5. **Календарь активностей**
**Файлы:**
- `src/panels/CalendarPanel.tsx`
- `src/components/Calendar.tsx`

**Функционал:**
- Календарное отображение активностей
- Отслеживание расскладов, аффирмаций, заметок
- Фильтрация по типам активностей
- Добавление новых записей

**Redux слайс:** `calendarSlice.ts`

### 6. **Настройки пользователя**
**Файл:** `src/panels/Settings.tsx`

**Функционал:**
- Выбор знака зодиака
- Переключение языка интерфейса (русский/английский)
- Настройка режима выбора карт (drag-and-drop / ручной)
- Сохранение предпочтений пользователя

**Redux слайсы:**
- `appSlice.ts` - общие настройки приложения
- `horoscopeSlice.ts` - настройки гороскопа

### 7. **Покупка звезд (Stars Purchase)**
**Файл:** `src/panels/StarsPurchase.tsx`

**Функционал:**
- Отображение пакетов звезд для покупки
- Интеграция с VK Payments (покупка за голоса ВК)
- Различные пакеты с бонусами
- Информация о применении звезд в приложении
- Обработка процесса покупки через VK Bridge

**Навигация:**
- Доступ через кнопку "Добавить звезды" в хедере (StarButton)
- Доступ через кнопку "Узнать больше" в баннере звезд на главной

**Пакеты звезд:**
- Малый: 100 звезд за 50 голосов
- Средний: 250 + 25 бонус за 100 голосов
- Большой: 500 + 70 бонус за 180 голосов (популярный)
- Мега: 1000 + 200 бонус за 300 голосов

## 🔄 Управление состоянием (Redux Store)

### Основные слайсы

1. **`appSlice.ts`**
   - Общие настройки приложения
   - Режим выбора карт
   - Вопрос пользователя

2. **`horoscopeSlice.ts`**
   - Знак зодиака пользователя
   - Язык интерфейса
   - Тип гороскопа (дневной/недельный/месячный)
   - Кэш гороскопов

3. **`taroDecksSlice.ts`**
   - Загруженные колоды карт
   - Детали карт
   - Состояния загрузки

4. **`taroSpreadsSlice.ts`**
   - Доступные расклады
   - Конфигурации расскладов

5. **`promptSlice.ts`**
   - Шаблоны промптов для ИИ
   - Генерация интерпретаций

6. **`calendarSlice.ts`**
   - События календаря
   - Активности пользователя

7. **`generationSlice.ts`**
   - Состояния генерации контента
   - История генераций
